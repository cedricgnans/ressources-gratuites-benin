# Ressources gratuites pour coder depuis le Bénin

Catalogue vérifié de ressources gratuites pour un étudiant en informatique au Bénin (Epitech Bénin) : offres étudiantes, API d'IA, crédits cloud, cours, plateformes d'entraînement, bourses et communautés.

- Site : https://cedricgnans.github.io/ressources-gratuites-benin/
- Catalogue Markdown : [ressources-gratuites-etudiant-info.md](ressources-gratuites-etudiant-info.md)
- Données structurées : [ressources.json](ressources.json)

Chaque ressource a été trouvée par recherche web puis contrôlée sur la page officielle du fournisseur (date de vérification dans chaque fiche). « À vérifier » signale une information non confirmée à la source, avec la raison. Les offres changent souvent : vérifiez avant de compter dessus.
